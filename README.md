# 🏍️ MotoMondiale 2026

Benvenuto nel repository di **MotoMondiale 2026**, un progetto personale sviluppato con l'obiettivo di realizzare un portale web moderno e completo dedicato alla stagione del Motomondiale.

Il sito raccoglie informazioni sulle principali categorie del campionato mondiale, offrendo un'interfaccia semplice, intuitiva e ricca di contenuti. Il progetto nasce dalla passione per il motorsport e dalla volontà di mettere in pratica competenze di sviluppo web attraverso la realizzazione di un sito strutturato e in costante evoluzione.

🌐 **Versione online**

https://paggii.github.io/moto2026/

---

# 📖 Descrizione del progetto

MotoMondiale 2026 è un sito realizzato interamente con tecnologie web front-end e pubblicato tramite GitHub Pages.

L'obiettivo è quello di creare un punto di riferimento dove consultare rapidamente informazioni riguardanti la stagione 2026 del Motomondiale, con una grafica moderna e una navigazione semplice.

Il progetto è stato sviluppato principalmente per approfondire lo sviluppo web, sperimentare nuove soluzioni grafiche e migliorare continuamente l'organizzazione dei contenuti.

Ogni sezione del sito è stata progettata per offrire un'esperienza piacevole sia da computer che da dispositivi mobili.

# 🎯 Obiettivi

Lo scopo principale del progetto è quello di creare un portale che possa offrire una panoramica completa della stagione del Motomondiale.

Durante lo sviluppo sono stati perseguiti diversi obiettivi:

- migliorare le competenze nello sviluppo web;
- realizzare un'interfaccia moderna e responsive;
- organizzare grandi quantità di informazioni in modo chiaro;
- mantenere uno stile grafico coerente in tutte le pagine;
- creare un progetto facilmente espandibile con nuove funzionalità.
